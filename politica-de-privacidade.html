Política de Privacidade

✅ Sem coleta de dados pessoais sensíveis

O aplicativo Meu Bolso - Controle Financeiro foi desenvolvido com foco total na privacidade do usuário. Esta política descreve de forma clara como tratamos as informações dentro do app.

1. Informações Coletadas

O app coleta apenas as informações estritamente necessárias para o funcionamento:

  • Endereço de e-mail: utilizado exclusivamente para criação de conta e login.
  • Dados de despesas: valores, descrições e datas inseridas pelo próprio usuário.

Não coletamos nome completo, CPF, dados bancários, localização, contatos ou qualquer outra informação pessoal sensível.

2. Como os Dados são Armazenados

Os dados do usuário são armazenados de duas formas:

  • Localmente no dispositivo: quando o usuário não está logado, os dados ficam salvos apenas no próprio celular/navegador (localStorage).
  • Na nuvem (Supabase): quando o usuário cria uma conta e faz login, os dados são sincronizados em um banco de dados seguro para permitir acesso em múltiplos dispositivos.

Cada usuário só tem acesso aos seus próprios dados. Não há compartilhamento entre contas.

3. Compartilhamento de Dados

Não vendemos, alugamos nem compartilhamos seus dados com terceiros para fins comerciais ou publicitários.

Os dados são armazenados na plataforma Supabase, que segue boas práticas de segurança e privacidade. Para mais informações, acesse a política de privacidade do Supabase.

4. Segurança

Adotamos medidas técnicas para proteger seus dados:

  • Autenticação segura por e-mail e senha
  • Cada usuário acessa apenas seus próprios dados (Row Level Security)
  • Comunicação criptografada via HTTPS

5. Direitos do Usuário

Você tem total controle sobre seus dados:

  • Exportar seus dados a qualquer momento (função disponível no app)
  • Excluir todos os seus dados pelo próprio app
  • Solicitar a exclusão da conta entrando em contato conosco

6. Uso por Menores

O aplicativo não é direcionado a crianças menores de 13 anos. Não coletamos intencionalmente dados de menores de idade.

7. Alterações nesta Política

Podemos atualizar esta política periodicamente. Em caso de alterações relevantes, o usuário será notificado dentro do próprio aplicativo.
