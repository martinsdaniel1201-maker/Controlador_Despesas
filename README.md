# 💰 Controlador de Despesas

Uma aplicação web moderna, responsiva e leve para gerenciamento de finanças pessoais. Desenvolvida como um **PWA (Progressive Web App)**, a ferramenta permite que você acompanhe suas receitas e despesas diretamente pelo navegador, com suporte a funcionamento offline e opção de instalação no celular ou computador.

---

## 🚀 Funcionalidades

* **Fluxo de Caixa:** Cadastro simples de Entradas (Receitas) e Saídas (Despesas).
* **Painel de Saldos:** Visualização dinâmica do total de entradas, saídas e o saldo atual.
* **Persistência de Dados:** Todos os registros são salvos no `localStorage` do navegador, garantindo que suas informações não sumam ao fechar a página.
* **Filtros por Categoria:** Organize e visualize seus gastos por tipo (Alimentação, Transporte, Lazer, Saúde, etc.).
* **Suporte PWA (Offline):** Graças ao Service Worker instalado, o aplicativo abre e funciona perfeitamente mesmo se você estiver sem conexão com a internet.

---

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando tecnologias web nativas, garantindo máxima performance:

* **HTML5:** Estruturação semântica da interface.
* **CSS3:** Estilização responsiva e moderna.
* **JavaScript (ES6):** Lógica de negócios, manipulação do DOM e armazenamento local.
* **PWA APIs:** Utilização de `manifest.json` e `Service Workers` para cache e instalabilidade.

---

## 📦 Como Executar o Projeto

Como o projeto utiliza apenas tecnologias front-end nativas, executá-lo localmente é extremamente simples:

1. Clone este repositório em sua máquina:
   ```bash
   git clone [https://github.com/Martinsdaniel1201-Maker/Controlador_Despesas.git](https://martinsdaniel1201-maker.github.io/Controlador_Despesas/)](https://github.com/Martinsdaniel1201-Maker/Controlador_Despesas.git)
Navegue até a pasta do projeto e abra o arquivo index.html diretamente em qualquer navegador de sua preferência.

Nota: Para que os recursos de PWA (como a instalação) funcionem perfeitamente, o projeto precisa ser servido através de uma conexão segura (HTTPS), o que já é feito automaticamente pelo GitHub Pages.

📱 Instalação (PWA)
Para instalar o app no seu dispositivo:

No Celular (Android/iOS): Abra o link do projeto no navegador (como Chrome ou Safari), clique no menu de opções e selecione "Adicionar à tela de início" ou "Instalar aplicativo".

No Computador: Clique no ícone de instalação que aparece diretamente na barra de endereços do navegador.
